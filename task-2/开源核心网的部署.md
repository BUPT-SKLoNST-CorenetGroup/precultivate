# 开源核心网的部署

## 1. 任务概述

通过本次任务，我们将会部署常见的开源核心网（free5gc），了解核心网的基本网元架构，并学习开源软件的编译。

本次任务需要使用到的工具有：

1. virtualbox，vmware，wsl2等等虚拟机软件，也可以安装linux+windows双系统，如果你并不熟悉linux安装，建议先从虚拟机开始上手，总之需要用一个linux的初始环境。

## 2. 任务描述

本次任务将分为两个部分。任务的目标不只是"把它跑起来"，更重要的是在部署过程中建立对核心网网元架构的直观认识。请在实验报告中记录你的部署过程、遇到的报错与解决方式，并尝试画出你部署的网元拓扑。

1. 参考[free5gc使用手册](https://free5gc.org/guide/)，按照 [Advanced] Build free5GC from scratch，从源码编译部署 free5gc。

> 注意 free5gc 对内核版本、gtp5g 内核模块、Go 版本等有要求，部署前先确认你的环境是否满足，这也是开源软件编译时最常见的坑。

   部署完成后，请尝试启动一个 UE 并完成注册、建立 PDU 会话，验证 UE 能够通过核心网访问外部网络。在报告中说明：UE 注册这一过程，依次经过了哪些网元？你是怎么从日志里看出来的？

2. 参考上述网页的 Configuration ULCL 部分，完成分流（ULCL）部分。

> ULCL（Uplink Classifier）会引入多个 UPF，请思考：分流到底分的是什么流量？分流规则在哪个网元、依据什么字段生效？完成后如何验证分流确实起作用了？

## 3. 需要掌握的知识

> 标有 `*` 的为通识/重点知识点，需要能够不假思索地解释清楚；其余知识点了解其基本内容、并知道如何查询即可。每个知识点后附有自测问题，你可以尝试回答这些问题来检测自己是否真正掌握。

1. ***5GC的基本网元**

   自测问题：
   - AMF、SMF、UPF、AUSF、UDM、NRF、PCF 分别负责什么？哪些属于控制面，哪些属于用户面？
   - 5GC 是如何做到控制面与用户面分离（CUPS）的？这样分离带来了什么好处？
   - 一个 UE 从开机到能上网，大致要和哪些网元打交道？UPF 在其中扮演什么角色？

2. **开源项目编译与通过日志进行debug**

   自测问题：
   - free5gc 各网元是用什么语言写的？它依赖哪些外部组件（如数据库、内核模块）？
   - 编译失败时，你如何判断是缺依赖、版本不匹配、还是环境配置问题？
   - 某个网元启动后立刻退出，你会去看哪些日志、关注哪些关键字来定位原因？

3. **ULCL 分流**

   自测问题：
   - ULCL 解决的是什么场景下的什么问题？为什么需要多个 UPF？
   - 分流规则（如基于目的 IP/DNN）配置在哪里、由哪个网元下发并执行？
   - 你用什么方法验证流量确实按预期被分流到了不同的 UPF？
