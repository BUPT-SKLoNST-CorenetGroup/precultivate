# 了解agent

> 该任务不强制所有同学完成，可在第task4的三个任务中各选一个

## 1. 任务概述

通过开源项目的学习，掌握agent的原理、实现方式，尝试搭建自己的agent。使用到的工具如下：

1. llm api 建议使用国内免费的api，阿里云、七牛云都提供免费的api额度；如果有能力，也可以使用openrouter提供的免费模型。
2. python

## 2. 任务描述

本次任务的目标是把"agent"从一个时髦词变成你能亲手实现、并讲清楚其内部循环的东西。请在实验报告中记录你跑通的阶段、关键代码的理解，以及你对"agent 的本质是什么"的回答。

1. 在github上clone相关代码[learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)
> learn-claude-code这个项目并不适合让你全面的了解claude-code，作为业界设计最好的agent，claude-code有太多工程上的考量，增加了很多功能，例如hooks等。这个项目很适合初学者了解agent的本质是什么，了解怎么设计自己的agent。

2. 按照个人能力完成如下章节
    
    a. 最低要求：完成阶段1
    b. 学有余力：完成阶段2
    c. 非常感兴趣：完成阶段3和4

| 阶段 | 目标 | 章节 |
|---|---|---|
| 阶段 1 | 先做出一个能工作的单 agent | `s01-s06` |
| 阶段 2 | 再补安全、扩展、记忆、提示词、恢复 | `s07-s11` |
| 阶段 3 | 把临时清单升级成真正的任务系统 | `s12-s14` |
| 阶段 4 | 从单 agent 升级成多 agent 与外部工具平台 | `s15-s19` |

> 跑通后建议停下来想一想：去掉花哨的封装，一个最小可用的 agent 到底由哪几部分组成？是什么让它能"自己决定下一步做什么"？

3. （可选）根据学习的情况，创建一个自己的agent，这个agent需要能够帮助你解决问题，例如论文解读、vibe coding。

> 这个agent需要是一个有价值的东西，要明确引入agent来做这件事的好处。

## 3. 需要掌握的知识

> 标有 `*` 的为通识/重点知识点，需要能够不假思索地解释清楚；其余知识点了解其基本内容、并知道如何查询即可。每个知识点后附有自测问题，你可以尝试回答这些问题来检测自己是否真正掌握。

1. **agent的核心概念**

   自测问题：
   - 一个最小 agent 的主循环大致是怎样的？（提示：调用 LLM → 解析输出 → 执行工具 → 把结果喂回去 → 再次调用）是什么决定了循环何时停止？
   - 什么是 tool / function calling？LLM 本身并不能执行代码，它是怎么"调用工具"的？
   - agent 的"记忆"和上下文是如何维护的？为什么上下文长度会成为一个需要管理的问题？
   - 单 agent 和多 agent 系统相比，各自适合解决什么样的问题？

2. **开源项目部署的能力**

   自测问题：
   - 拿到一个陌生的开源项目，你按什么顺序去读它、把它跑起来？（README、依赖、配置、入口）
   - 这个项目需要配置 LLM API 的哪些信息（api_key、base_url、模型名）？这些信息应该怎样安全地管理，而不是硬编码进代码？

> 该项目类似教程，属于非常好部署的开源项目了
