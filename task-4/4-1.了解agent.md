# 了解agent

> 该任务不强制所有同学完成，可在第task4的三个任务中各选一个

## 1. 任务概述

通过开源项目的学习，掌握agent的原理、实现方式，尝试搭建自己的agent。使用到的工具如下：

1. llm api 建议使用国内免费的api，阿里云、七牛云都提供免费的api额度；如果有能力，也可以使用openrouter提供的免费模型。
2. python

## 2. 任务描述

本次任务分为如下步骤：

1. 在github上clone相关代码[learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)
> learn-claude-code这个项目并不适合让你全面的了解claude-code，作为业界设计最好的agent，claude-code有太多工程上的考量，增加了很多功能，例如hooks等。这个项目很适合初学者了解agent的本质是什么，了解怎么设计自己的agent。

2. 按照个人能力完成如下章节
    
    a. 最低要求：完成阶段1
    b. 学有余力：完成阶段2
    c. 非常感兴趣：完成阶段3和4

| 阶段 | 目标 | 章节 |
|---|---|---|
| 阶段 1 | 先做出一个能工作的单 agent | `s01-s06` |
| 阶段 2 | 再补安全、扩展、记忆、提示词、恢复 | `s07-s11` |
| 阶段 3 | 把临时清单升级成真正的任务系统 | `s12-s14` |
| 阶段 4 | 从单 agent 升级成多 agent 与外部工具平台 | `s15-s19` |


3. （可选）根据学习的情况，创建一个自己的agent，这个agent需要能够帮助你解决问题，例如论文解读、vibe coding。

> 这个agent需要是一个有价值的东西，要明确引入agent来做这件事的好处。

## 3. 需要掌握的知识

1. agent的核心概念
2. 开源项目部署的能力
